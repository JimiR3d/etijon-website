# Etijon Foundation Website

## Overview
Etijon is a charity foundation website pixel-perfect recreation based on Figma design exports and screenshots.

## Stack
- **Frontend:** HTML5, CSS3 (Vanilla CSS with CSS Custom Properties/Variables), Vanilla JavaScript
- **Fonts:** Inter (via Google Fonts)
- **Deployment:** Static Web Application (Live GitHub: `https://github.com/JimiR3d/etijon-website`)

## Design Tokens
- `--primary-color`: `#001D50`
- `--secondary-color`: `#EBAC00`
- `--bg-color`: `#1E1E1E`
- `--font-family`: `'Inter', sans-serif`
